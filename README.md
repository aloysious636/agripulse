# AgriPulse — Smarter Livestock Management

Offline-first multi-species livestock and farm management desktop software built with Python, Flask, SQLAlchemy, SQLite, Waitress, and pywebview.

## Commands
- Run Tests: `pytest -v`
- Launch Desktop App: `python desktop.py`
- Launch Web Dev Server: `python run.py`
- Build Windows EXE: `pyinstaller agripulse.spec --clean`
